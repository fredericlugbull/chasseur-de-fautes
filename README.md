# Chasseur de fautes

Jeu d'orthographe gratuit pour le CM2 : accords, é ou er, homophones, nombres, dictées… et une partie de Mot Blaster pour finir.

**Jouer : https://fredericlugbull.github.io/chasseur-de-fautes/**

- Gratuit, sans publicité, sans compte.
- Rien n'est envoyé sur Internet : le prénom et la progression restent dans le navigateur de l'appareil.
- Téléphone, tablette ou ordinateur.

## Pour les parents

- **Les mots de la semaine.** En bas de l'accueil : « Pour les parents » → « Espace adultes ». Tapez les mots donnés par la maîtresse, un par ligne (avec, si vous voulez, une courte phrase après un point-virgule), puis « Créer le lien ». Chaque enfant qui ouvre ce lien retrouve les mots dans sa mission Dictée.
- **Ouvrez le lien dans le navigateur où l'enfant joue** (Safari, Chrome…). Sur iPhone, depuis WhatsApp ou un autre message, choisissez « Ouvrir dans Safari » : sinon les mots arrivent dans un autre navigateur.
- **Sauvegarde.** Safari peut effacer les données d'un site qui n'a pas été ouvert depuis une semaine. Avant des vacances, « Télécharger une sauvegarde » dans l'Espace adultes ; « Restaurer une sauvegarde » la remet en place.

## Technique

- Un seul fichier `index.html`, sans serveur ni dépendance. Polices Lexend et Bungee incluses (licence SIL Open Font License 1.1, voir `fonts/`).
- Hébergé avec GitHub Pages.
- Les phrases d'exemple citent des univers connus des enfants (Pokémon, Zelda, Naruto…) ; ce projet n'est affilié à aucun d'eux.

Fait par un papa de la classe, avec l'aide de Claude (Anthropic).
